# Security Policy

## Supported versions

Security fixes are applied on the `master` branch. Use the latest release from that branch.

## Reporting a vulnerability

If you discover a security issue, please open a [private security advisory](https://github.com/hippi345/randobotjava/security/advisories/new) on GitHub or contact the repository owner. Do not open a public issue for sensitive reports.

We will acknowledge reports as quickly as possible and work on a fix or mitigation.

## Secrets and credentials

This project is a local desktop game and does not require API keys or cloud credentials. Do not commit secrets to the repository.
